ເປີດແອັບ
ທ່ານເປີດຈາກ Facebook / WhatsApp / LINE. ກົດ ⋮ ຫຼື ⋯ → ເປີດໃນ Chrome (Android) ຫຼື Safari (iPhone) ກ່ອນ ເພື່ອເພີ່ມໃສ່ໜ້າຈໍ.
📲 ເພີ່ມໃສ່ໜ້າຈໍ iPhone
  1. ເປີດໜ້ານີ້ໃນ Safari
  2. ກົດປຸ່ມ ແບ່ງປັນ ⬆ ທາງລຸ່ມ
  3. ເລືອກ ເພີ່ມໃສ່ໜ້າຈໍໂຮມ (Add to Home Screen)
  4. ກົດ ເພີ່ມ
📲 ເພີ່ມໃສ່ໜ້າຈໍ Android
  1. ເປີດໜ້ານີ້ໃນ Chrome
  2. ກົດ ⋮ ມຸມຂວາເທິງ
  3. ເລືອກ ເພີ່ມໃສ່ໜ້າຈໍຫຼັກ ຫຼື ຕິດຕັ້ງແອັບ
  4. ກົດ ເພີ່ມ / ຕິດຕັ້ງ
